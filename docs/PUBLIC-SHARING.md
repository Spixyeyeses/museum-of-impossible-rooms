# Public-sharing copy

## Unity preview publication

The Unity preview adds the native project, export tools, tests, release docs and selected visual evidence. Only Assets, Packages and ProjectSettings are included from the Unity project. Local service associations, caches, connection credentials, build folders and personal saves are excluded. The Windows build is distributed as a versioned GitHub release asset with its verification record and SHA-256.

## Browser v1.0.0 provenance

This repository source was prepared from the verified local release archive whose SHA-256 is `159cc8a35b8c58ba3f3bfa6196c29294db8afa4dade6e9c04b5be8e3b8ea9aab`. The original local archive and original evidence were preserved unchanged.

All gameplay source, assets, bundled dependencies and license, launchers, server, tools, and tests are byte-for-byte copies of the verified release. Repository metadata and documents are the only changed files.

Copied documents and evidence are explicitly labeled sanitized copies. Machine-specific absolute filesystem paths are replaced with `[WORKSPACE]`, `[BROWSER_EXECUTABLE]`, `[LOCAL_IMAGEGEN_OUTPUT]`, or other descriptive placeholders. Antivirus-injected request identifiers are removed while the observed host-injection caveat remains. Test outcomes, source hashes, versions, timings, and stated limitations are retained.

Raw development screenshots, duplicate clean extractions, generated archives, and personal save files are not included in this source folder. Screenshot entries in reports refer to omitted historical evidence; they do not assert that those images are present here. The original archive manifest is omitted because it describes the original document bytes. A new distribution can generate its own accurate manifest with `node tools/package.mjs`.

The sanitized [clean-installation record](../evidence/clean-install-verification.json) refers to the original verified local archive. A new archive built from this public source has a different hash because repository documents have changed; it should be labeled and verified as that separate distribution.
